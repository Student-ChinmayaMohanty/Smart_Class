## 📖 Overview

**SmartClass** is an AI-powered classroom management system that automates student attendance using facial recognition. The application provides a modern dashboard where teachers can register students, recognize faces in real time, manage attendance records, and monitor classroom activities efficiently.

Designed with **Streamlit**, **OpenCV**, **Face Recognition**, and **Supabase**, SmartClass offers a fast, secure, and user-friendly experience.

## ✨ Features

### 👨‍🎓 Student Management

# ⚙️ Installation

### Clone Repository


```bash

```

### Install Requirements


